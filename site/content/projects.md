# 프로젝트 및 개발 활동

학교 수업과 개인 학습을 통해 습득한 프로그래밍 지식을 실제 개발에 적용하기 위해 다양한 기술을 학습하고 있습니다.

특히 Python을 활용한 백엔드 개발과 웹서비스의 동작 구조에 관심을 가지고 있으며, 직접 프로젝트를 진행하면서 서버와 데이터베이스, 개발 도구를 활용하는 경험을 쌓았습니다.

## Blog Term - RESTful 블로그 API 서버 개발

**프로젝트 기간:** 2025년 12월 (GitHub 기록 기준)

**프로젝트 유형:** 개인 프로젝트

**진행 상태:** 완료

**GitHub:** https://github.com/goodabcdef/blog_term

**사용 기술:** Python, FastAPI, MySQL, SQLAlchemy, Redis, JWT, Docker, GitHub Actions

### 1. 프로젝트 개요

Blog Term은 사용자가 게시글을 작성하고 관리할 수 있도록 RESTful API 기반의 블로그 백엔드 서버를 개발한 개인 프로젝트입니다.

사용자 인증, 게시글 관리, 댓글과 좋아요 등의 기능을 제공하는 서버를 구성하고, 데이터베이스와 캐싱 시스템을 연동하는 것을 주요 목표로 하였습니다.

또한 Docker를 활용한 실행 환경 구성과 GitHub Actions를 통한 자동 테스트 환경을 적용하여 실제 웹서비스의 백엔드 구조와 개발 과정을 이해하고자 하였습니다.

### 2. 프로젝트 목적

이 프로젝트의 주요 목적은 Python과 FastAPI를 활용하여 웹서비스의 핵심 기능을 제공하는 RESTful API 서버를 구현하는 것이었습니다.

단순히 개별 기능을 개발하는 것에서 그치지 않고, 사용자 요청을 처리하는 서버와 데이터를 저장하는 데이터베이스가 서로 연결되는 구조를 이해하고자 하였습니다.

또한 사용자 인증과 접근 권한 관리, 캐싱, 컨테이너 기반 실행 환경 등 다양한 백엔드 기술을 하나의 프로젝트에 적용하는 경험을 쌓는 것을 목표로 하였습니다.

### 3. 담당 역할

개인 프로젝트로 진행하였으며, 프로젝트의 개발과 관리 전반을 직접 담당하였습니다.

주요 작업 범위는 다음과 같습니다.

- FastAPI 기반 백엔드 서버 구성
- 사용자 인증 및 게시글 관리 API 개발
- MySQL과 SQLAlchemy를 활용한 데이터베이스 연동
- Redis를 활용한 캐싱 및 요청 제한 기능 구성
- Docker Compose 기반 실행 환경 설정
- GitHub Actions를 활용한 자동 테스트 환경 구성
- 프로젝트 코드 및 관련 문서 관리

### 4. 주요 구현 기능

**사용자 인증 및 권한 관리**

JWT를 활용하여 로그인과 토큰 갱신 기능을 구성하였습니다.

또한 일반 사용자와 관리자 권한을 구분하여 각 사용자에게 허용된 기능에 접근할 수 있도록 설계하였습니다.

**게시글 및 댓글 관리**

게시글 작성, 조회, 수정, 삭제 기능을 제공하는 RESTful API를 구성하였습니다.

댓글 관리와 좋아요, 태그 기능도 포함하여 블로그 서비스에서 필요한 기본적인 사용자 상호작용을 처리할 수 있도록 하였습니다.

**데이터베이스 연동**

MySQL과 SQLAlchemy를 사용하여 사용자 정보와 게시글 데이터를 관리하는 구조를 구성하였습니다.

이를 통해 API 서버가 데이터베이스에 정보를 저장하고 조회하는 방식을 학습하였습니다.

**Redis 캐싱 및 요청 제한**

Redis를 활용하여 게시글 조회수 캐싱과 요청 제한 기능을 구성하였습니다.

반복적인 데이터 조회와 과도한 요청을 효율적으로 처리하기 위한 기술을 학습하였습니다.

**Docker 및 자동화 환경**

Docker Compose를 활용하여 애플리케이션과 MySQL, Redis를 함께 실행할 수 있는 환경을 구성하였습니다.

GitHub Actions를 이용하여 코드 변경 시 자동으로 테스트를 실행하는 CI 워크플로를 설정하였습니다.

### 5. 프로젝트 수행 과정

**첫 번째 단계: 기능 정의 및 서버 구조 설계**

블로그 서비스에 필요한 사용자 인증, 게시글 관리, 댓글, 좋아요 등의 주요 기능을 정리하고 API 구조를 구성하였습니다.

**두 번째 단계: API 및 데이터베이스 개발**

FastAPI를 사용하여 HTTP 요청을 처리하는 서버를 구성하고, MySQL과 SQLAlchemy를 연동하여 데이터를 저장하고 관리하도록 하였습니다.

**세 번째 단계: 인증 및 부가 기능 구성**

JWT 인증과 사용자별 접근 권한을 구분하는 기능을 구성하였습니다.

또한 Redis를 연동하여 캐싱과 요청 제한 기능을 추가하였습니다.

**네 번째 단계: 실행 환경 및 테스트 구성**

Docker Compose를 활용하여 서버 실행 환경을 구성하고, GitHub Actions를 통해 자동 테스트를 수행할 수 있는 워크플로를 설정하였습니다.

### 6. 기술 및 개발 방법 선택 이유

**FastAPI**

Python을 기반으로 API를 개발할 수 있고, 자동 API 문서 생성 기능을 제공한다는 점에서 활용하였습니다.

이를 통해 API의 구조를 이해하고 요청과 응답을 확인하는 방법을 학습할 수 있었습니다.

**MySQL / SQLAlchemy**

사용자와 게시글처럼 서로 관계가 있는 데이터를 체계적으로 관리하기 위해 관계형 데이터베이스를 활용하였습니다.

SQLAlchemy를 통해 Python 코드에서 데이터베이스를 다루는 방법을 학습하였습니다.

**Redis**

반복적인 데이터 접근을 줄이고 서버 요청을 효율적으로 처리하는 캐싱 기술을 경험하기 위해 사용하였습니다.

**Docker Compose**

애플리케이션과 데이터베이스 등 여러 서비스를 일관된 환경에서 실행하고 관리하기 위해 활용하였습니다.

**GitHub Actions**

코드 변경 이후 테스트 과정을 자동으로 실행하고, 반복적인 검증 작업을 효율적으로 관리하기 위해 활용하였습니다.

### 8. 배운 점과 한계

이번 프로젝트를 통해 백엔드 개발에는 단순한 API 구현뿐만 아니라 데이터베이스 설계, 인증, 서버 실행 환경, 테스트 등 여러 기술에 대한 이해가 필요하다는 점을 배웠습니다.

특히 FastAPI와 MySQL을 연동하는 과정에서 서버와 데이터베이스 사이의 데이터 처리 구조를 학습할 수 있었습니다.

또한 Redis와 Docker를 활용하면서 서버 성능을 고려하는 방법과 실행 환경을 관리하는 방법에 대해 이해를 넓힐 수 있었습니다.

한편 다양한 기능을 구현하더라도 실제 사용 환경에서 발생할 수 있는 오류와 예외 상황을 충분히 검증하는 것이 중요하다는 점을 알게 되었습니다.

### 9. 향후 개선 방향

프로젝트는 완료하였지만, 학습과 기술 발전을 위해 다음과 같은 부분을 개선해 보고 싶습니다.

먼저 API의 정상 동작뿐만 아니라 잘못된 입력과 예외 상황을 확인하는 테스트를 보강할 계획입니다.

또한 데이터베이스 조회와 Redis 캐싱 구조를 검토하여 서버의 처리 효율을 높이는 방법을 학습하고 싶습니다.

나아가 프론트엔드와 백엔드를 연결하여 사용자가 실제 웹페이지에서 게시글을 작성하고 관리할 수 있는 형태로 발전시키는 것도 목표입니다.

이번 프로젝트를 통해 얻은 경험을 바탕으로 앞으로 더 안정적이고 효율적인 백엔드 서비스를 개발할 수 있도록 꾸준히 학습하겠습니다.
