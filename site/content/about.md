# 안녕하세요, 김성진입니다.

컴퓨터공학을 공부하고 있는 김성진입니다.

저는 프로그래밍과 소프트웨어 개발에 관심이 있으며, 특히 웹서비스가 동작하는 원리와 서버에서 데이터를 처리하는 과정에 흥미를 가지고 있습니다.

학교 수업을 통해 프로그래밍의 기초 개념을 학습하고, 배운 내용을 직접 구현하면서 개발에 대한 이해를 넓혀 가고 있습니다.

또한 개인 프로젝트를 통해 다양한 개발 기술을 활용하고, 프로그램을 구성하는 여러 요소가 어떻게 연결되는지 경험하고 있습니다.

앞으로 꾸준한 학습과 프로젝트 경험을 바탕으로 문제를 논리적으로 분석하고 해결할 수 있는 개발자로 성장하는 것이 목표입니다.

## 관심 분야

### 웹 개발

평소 사용하는 웹사이트가 어떤 기술로 만들어지고, 사용자의 요청에 따라 어떻게 동작하는지 궁금해 웹 개발에 관심을 갖게 되었습니다.

특히 웹페이지의 화면뿐만 아니라 사용자 요청을 처리하는 서버와 데이터를 관리하는 데이터베이스가 서로 연결되는 과정에 흥미를 느끼고 있습니다.

현재 HTML과 CSS를 통해 웹페이지의 구조와 디자인을 학습하고 있으며, 앞으로 JavaScript를 공부하여 사용자와 상호작용하는 웹페이지를 구현하고 싶습니다.

### 백엔드 개발

웹서비스의 데이터를 처리하고 관리하는 백엔드 개발에 관심이 있습니다.

사용자가 로그인하거나 게시글을 작성하는 과정에서 서버가 요청을 처리하고 데이터베이스에 정보를 저장하는 방식이 흥미롭다고 생각합니다.

이러한 관심을 바탕으로 Python과 FastAPI를 활용한 개인 프로젝트를 진행하며 RESTful API 서버의 기본 구조를 학습하였습니다.

앞으로는 서버와 데이터베이스의 동작 원리를 더욱 깊이 이해하고, 안정적이고 효율적인 백엔드 시스템을 개발하는 능력을 기르고 싶습니다.

### 프로그래밍과 문제 해결

프로그래밍은 단순히 코드를 작성하는 것이 아니라 주어진 문제를 분석하고 논리적인 방법으로 해결하는 과정이라고 생각합니다.

프로그램을 작성하다 보면 예상하지 못한 오류가 발생할 수 있으며, 이러한 문제의 원인을 파악하고 수정하는 과정도 개발에서 중요한 부분이라고 생각합니다.

앞으로 다양한 프로그래밍 언어와 알고리즘을 학습하고, 직접 문제를 해결하는 경험을 쌓아 논리적인 사고력과 문제 해결 능력을 발전시키고 싶습니다.

## 보유 역량 및 활용 경험

### Python

Python의 기본 문법을 학습하였으며, 변수와 자료형, 조건문, 반복문, 함수 등을 활용한 프로그래밍 방법을 익혔습니다.

또한 개인 프로젝트인 Blog Term에서 Python 기반의 FastAPI 프레임워크를 활용하여 백엔드 API 서버를 구성하는 경험을 쌓았습니다.

이를 통해 기초 프로그래밍 지식을 실제 소프트웨어 개발에 적용하는 방법을 학습하였습니다.

### FastAPI

FastAPI를 활용하여 RESTful API 서버를 구성하고 HTTP 요청과 응답을 처리하는 방법을 학습하였습니다.

Blog Term 프로젝트에서 사용자 인증과 게시글 관리 등의 API를 다루면서 백엔드 서버의 구조와 동작 원리에 대한 이해를 높였습니다.

### MySQL / SQLAlchemy

MySQL과 SQLAlchemy를 활용하여 데이터베이스와 서버를 연동하는 방법을 학습하였습니다.

Blog Term 프로젝트에서 사용자와 게시글 관련 데이터를 저장하고 관리하는 구조를 구성하면서 데이터베이스의 역할과 데이터 처리 과정에 대해 이해할 수 있었습니다.

### Docker / Redis

Docker와 Docker Compose를 활용하여 애플리케이션과 데이터베이스를 함께 실행하는 환경을 구성해 보았습니다.

또한 Redis를 활용한 캐싱과 요청 제한 기능을 다루면서 서버의 성능과 효율성을 개선하기 위한 기술에 대해 학습하였습니다.

### Git / GitHub

Git과 GitHub를 활용하여 소스 코드의 변경 사항을 기록하고 프로젝트를 관리하는 방법을 익혔습니다.

개인 프로젝트의 소스 코드와 관련 자료를 GitHub 저장소에 정리하면서 버전 관리의 중요성을 이해하였습니다.

또한 GitHub Actions를 활용한 자동 테스트 환경을 구성하는 경험을 통해 개발 과정의 자동화에 대해서도 학습하였습니다.

### HTML / CSS

HTML을 활용하여 웹페이지의 기본적인 구조를 작성하고, CSS를 이용하여 글자와 색상, 배치 등의 디자인을 설정하는 방법을 학습하고 있습니다.

앞으로 다양한 웹페이지를 직접 구현하면서 HTML과 CSS 활용 능력을 높이고, 반응형 웹 디자인에 대해서도 공부할 계획입니다.

## 학습 목표

### 1. 프로그래밍 기초 역량 강화

프로그래밍 언어의 기본 문법을 정확하게 이해하고, 다양한 문제를 스스로 해결할 수 있는 능력을 기르고 싶습니다.

이를 위해 Python의 기본 개념을 꾸준히 복습하고, 조건문과 반복문, 함수 등을 활용하는 프로그래밍 문제를 직접 풀어볼 계획입니다.

이후 알고리즘과 자료구조 학습으로 범위를 넓혀 보다 효율적으로 문제를 해결하는 방법을 익히겠습니다.

### 2. 웹 개발 및 백엔드 기술 학습

웹페이지와 백엔드 서버가 서로 연결되어 하나의 서비스를 구성하는 과정을 이해하는 것이 목표입니다.

이를 위해 HTML, CSS, JavaScript를 단계적으로 학습하고, FastAPI를 활용한 API 개발과 데이터베이스 연동 방법을 더욱 깊이 공부할 계획입니다.

또한 간단한 웹페이지와 API 서버를 직접 연결하는 프로젝트를 진행하면서 실제 웹서비스의 동작 과정을 경험하고 싶습니다.

### 3. GitHub를 활용한 프로젝트 관리

GitHub를 활용하여 학습 내용과 프로젝트 결과물을 체계적으로 관리하는 능력을 기르고 싶습니다.

이를 위해 수업에서 작성한 코드와 개인 프로젝트를 저장소별로 정리하고, README를 통해 프로젝트의 목적과 실행 방법을 기록할 계획입니다.

또한 코드의 변경 사항을 의미 있는 커밋으로 관리하며 꾸준히 개발 기록을 남기는 습관을 기르겠습니다.

### 4. 문제 해결 및 개발 역량 향상

프로그램을 개발하는 과정에서 발생하는 문제를 스스로 분석하고 해결할 수 있는 능력을 키우고 싶습니다.

오류가 발생했을 때 실행 결과와 오류 메시지를 확인하고, 공식 문서와 학습 자료를 참고하여 원인을 파악하는 연습을 지속하겠습니다.

또한 기존 프로젝트의 코드를 개선하거나 새로운 기능을 추가하는 경험을 통해 실제 개발 능력을 발전시키고 싶습니다.

## 앞으로의 계획

앞으로는 학교 수업에서 배운 컴퓨터공학 지식을 바탕으로 다양한 개발 경험을 쌓아 나갈 계획입니다.

먼저 프로그래밍의 기초를 더욱 탄탄하게 다지고, 웹 개발과 백엔드 기술에 대한 이해를 넓히고 싶습니다.

특히 개인 프로젝트에서 경험한 API 개발과 데이터베이스 연동 기술을 발전시키고, 새로운 프로젝트를 진행하면서 다양한 기술을 직접 적용해 보고자 합니다.

또한 GitHub에 학습 과정과 프로젝트 결과물을 꾸준히 기록하며, 부족한 부분을 파악하고 개선하는 습관을 기르겠습니다.

**꾸준한 학습과 실습을 통해 새로운 기술에 적응하고, 문제를 스스로 분석하고 해결할 수 있는 개발자로 성장하겠습니다.**
