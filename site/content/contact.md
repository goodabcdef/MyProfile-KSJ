# 연락 및 활동 링크

안녕하세요. 컴퓨터공학을 공부하고 있는 김성진입니다.

프로그래밍과 웹 개발, 백엔드 기술에 관심을 가지고 있으며, 다양한 개발 기술을 학습하고 개인 프로젝트를 진행하고 있습니다.

GitHub를 통해 프로젝트 소스 코드와 개발 활동을 정리하고 있습니다.

## GitHub

**GitHub 프로필**

https://github.com/goodabcdef

GitHub에 프로그래밍 학습 내용과 개인 프로젝트의 소스 코드를 기록하고 있습니다.

프로젝트별 저장소에서 사용한 기술과 개발 결과물을 확인할 수 있습니다.

## 대표 프로젝트

**Blog Term - RESTful 블로그 API 서버**

https://github.com/goodabcdef/blog_term

Python과 FastAPI를 기반으로 개발한 개인 블로그 API 서버 프로젝트입니다.

사용자 인증, 게시글 관리, 데이터베이스 연동, Docker 기반 실행 환경 구성 등 백엔드 개발 경험을 담고 있습니다.

자세한 프로젝트 소개와 수행 과정은 사이트의 프로젝트 페이지에서 확인할 수 있습니다.

## 앞으로의 활동

앞으로도 학습한 내용을 GitHub에 꾸준히 기록하고, 새로운 기술을 활용한 프로젝트를 진행할 계획입니다.

다양한 개발 경험을 쌓으면서 소프트웨어 개발 능력과 문제 해결 역량을 발전시키겠습니다.
